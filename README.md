# METU CENG 140 — C Systems & Algorithms Portfolio

A collection of systems-level programming assignments, memory management laboratories, and data structures implemented in ANSI C (C89) for **CENG 140: C Programming** at Middle East Technical University (METU / ODTÜ).

Developed by [Görkem Akbulut](https://github.com/GioGorkem) (METU Computer Engineering).

---

## Portfolio Modules

* **`01_fundamentals_and_prelabs/`**: Algorithmic problem solving, low-level I/O streams, digit manipulations, and pattern analysis.
* **`02_recursion_wave_pressure/`**: Recursive seismic pressure wave attenuation simulation modeling energy transfer across variable subterranean rock layers.
* **`03_dynamic_memory_and_strings/`**: Dynamic 2D matrix allocation, in-place token redaction, and astronomical sunset & coordinate shift calculations.
* **`04_advanced_linked_lists/`**: Singly and doubly linked list architectures, multi-level pointer manipulation (`Node**`), priority-based spaceship fleet sorting, and circular route traversal.
* **`05_distributed_sensor_network/`**: Multi-zone sensor registry, dynamic snapshot aggregation, multi-criteria struct sorting, and strict memory deallocation verified with Valgrind.

---

## Technical Highlights
* **Standard:** ANSI C (C89) compliant, compiled with strict flags (`-Wall -Wextra`).
* **Memory Safety:** Explicit dynamic allocation (`malloc`, `realloc`, `free`) with zero memory leaks verified via Valgrind.
* **Pointer Architectures:** Deep copies, sentinel nodes, and double-pointer list operations.
